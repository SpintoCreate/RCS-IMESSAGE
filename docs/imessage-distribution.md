# iMessage component distribution review

Checked 2026-10-22. This is a practical release gate, not legal advice. It is separate from whether activation works. A locally built diagnostic APK is not evidence that redistribution is cleared.

| Component | Public terms found | Requirement before distributing a build containing it |
| --- | --- | --- |
| [OpenBubbles/rustpush](https://github.com/OpenBubbles/rustpush/blob/a7fab473e7a33325a760635285db2860de8e1cb0/LICENSE) | SSPL-1.0. Its [exception](https://github.com/OpenBubbles/rustpush/blob/a7fab473e7a33325a760635285db2860de8e1cb0/LICENSE.exceptions) expressly grants broad rights to **OpenBubbles**, including the ability to permit recipients to do so. No grant expressly naming UnifiedMessages or its maintainer was found. | Before sharing an APK or service that includes rustpush, obtain a clear applicable permission from its rights holders **or** obtain legal review and meet the applicable SSPL source, notice, and distribution obligations. The Apache license on OpenBubbles' app does not relicense the rustpush submodule. Do not assume OpenBubbles' exception automatically covers an unrelated app. |
| [OpenBubbles/openbubbles-app](https://github.com/OpenBubbles/openbubbles-app/blob/eed1b6332efbb17adbf5ebfa2263ad770169f75e/LICENSE) | Apache-2.0 for that app's own source. | If app source is ported or copied, preserve the Apache license and notices. | [StablePush](https://github.com/SpintoCreate/StablePush/tree/d1237b401fef50b38236366b3025c1606400777a) or [OpenBubbles/relayserver](https://github.com/OpenBubbles/relayserver/tree/630721fef21e3d072e72d92df957a66c0b2b0851) | No repository `LICENSE` file was present at the inspected revisions. The upstream ValidationRelay and other dependencies need their own review. | Do not copy or redistribute relay source/binaries in this app without a documented license or permission. The Android module currently includes neither. |

The repository's feature branch contains a **debug-only opt-in** dependency on `:imessage-native`; the release APK built with that opt-in flag excluded the native library. The debug AAR/APK still contain a rustpush-derived binary with upstream's compile-only legacy FairPlay placeholders, so they are not cleared for public distribution by the release exclusion. The untracked `gmessages/` spike was not touched. The app's own repository has no root `LICENSE` file; decide its distribution terms separately before publication.

Before any public APK, Play listing, hosted service, or merged production iMessage provider: resolve the rustpush permission/compliance question in writing; review every copied relay component and build artifact; provide required notices/source where applicable; and verify that no private activation assets, user credentials, identifiers, or messages are packaged or logged. Technical registration success does not replace this release review.
